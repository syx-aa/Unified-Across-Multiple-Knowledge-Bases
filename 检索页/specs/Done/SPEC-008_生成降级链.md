## 1. 需求（Spec）

大模型通道可能因域名未授权、网络中断、服务报错而不可用。
任何失败都必须**明确告知用户并给出替代内容**，不允许白屏或静默失败。

## 2. 验收标准（AC）

- [x] AC3：流中断时保留已生成内容，不丢弃
- [x] AC4：`file://` 直接打开也能看到答案（走本地摘要）
