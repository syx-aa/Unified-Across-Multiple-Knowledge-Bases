# SPEC-009 检索过程 trace 面板

> 状态：Done ｜ 优先级：P2 ｜ 归属：前端 ｜ 更新：2026-10-23

## 1. 需求（Spec）

答案从哪来要看得见。问答卡上方放一个可折叠面板，把检索链路逐步摊开，
便于演示、面试和自查「为什么是这个结果」。

## 2. 验收标准（AC）

- [x] AC1：7 个步骤依次展示：分词 → 关键词路 → 实体路 → 归一化融合 → 相关度闸门 → 取料 → 生成
- [x] AC2：分词步列出前 12 个词元（中文相邻二字 + 英文数字词）
- [x] AC3：面板头部显示总步数与检索耗时（ms）
- [x] AC4：可折叠 / 展开
- [x] AC5：无结果时第 5 步（闸门）标红并给出拦截原因，第 7 步显示「未生成」
- [x] AC6：服务端检索时标注服务端步骤
