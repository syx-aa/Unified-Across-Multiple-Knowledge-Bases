# SPEC-001 关键词检索（BM25 + bigram）

> 状态：Done ｜ 优先级：P0 ｜ 归属：检索层 ｜ 更新：2026-10-23

## 1. 需求（Spec）

用户输入问题后，按**字面精确匹配**召回资料，擅长专名、数字、固定短语（如「26人大名单」「7.5亿」）。
中文无空格，故用二元切分（bigram）建倒排索引，再用 BM25 打分排序。

边界：不做语义理解，换种说法问就召回不到（那是 SPEC-003 的职责）。

## 2. 验收标准（AC）

- [x] AC1：中文按相邻二字切分（bigram），英文/数字按词切分
- [x] AC2：倒排索引在页面启动时即时构建，耗时 < 100ms
- [x] AC3：BM25 排序，**标题权重 ×3**
- [x] AC4：单次关键词检索 < 10ms
- [x] AC5：服务端（`server.py`）复刻的 BM25 与前端聚合指标一致
