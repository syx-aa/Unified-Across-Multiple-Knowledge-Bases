# SPEC-004 三路融合检索

> 状态：Done ｜ 优先级：P0 ｜ 归属：检索层 ｜ 更新：2026-10-23

## 1. 需求（Spec）

关键词、实体、向量三路各有擅长，需要一套**可解释、可回归**的融合规则把三路结果合成一份排序。

关键决策：**用固定权重，不用大模型路由**（放弃理由见 SPEC-017）。

## 2. 验收标准（AC）

- [x] AC1：三路得分各自归一化后再加权，消除量纲差异
- [x] AC2：权重 `0.45 × 关键词 + 0.25 × 实体 + 0.30 × 向量`
- [x] AC3：候选 = 融合 top-30 ∪ 向量 top-30（保证语义路不被权重稀释掉）
- [x] AC4：总体 Hit@1 相对纯 BM25 基线**不下降**
- [x] AC5：权重集中定义、可一处修改
