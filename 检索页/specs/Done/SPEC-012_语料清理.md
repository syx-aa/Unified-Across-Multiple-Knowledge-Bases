# SPEC-012 语料清理

> 状态：Done ｜ 优先级：P1 ｜ 归属：数据层 ｜ 更新：2026-10-11

## 1. 需求（Spec）

用评测结果反查数据质量：语料里有 21 篇「用户名 + 日期」型抓取噪音
（彩票票面、求带、视频目录等），它们污染检索结果、也让优化失去干净的对照组。

## 2. 验收标准（AC）

- [x] AC1：噪音篇目归档到 `_archived/`，可回滚
- [x] AC2：有真实内容但标题是用户名的，改名保留
- [x] AC3：失效引用与改名引用同步剪枝
- [x] AC4：重算节点页「关联笔记 N 篇」计数
- [x] AC5：全量备份存在，可完整回滚
- [x] AC6：清理后总体指标**不下降**

## 5. 验证结果

| 处理 | 数量 |
|---|---|
| 归档 | 18 篇（12 纯噪音 + 6 重复） |

| 原样保留 | 1 篇（2022 赛事集锦） |
