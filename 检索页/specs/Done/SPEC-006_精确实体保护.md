# SPEC-006 精确实体命中保护

> 状态：Done ｜ 优先级：P0 ｜ 归属：检索层 ｜ 更新：2026-10-23

## 1. 需求（Spec）

上重排后发现一个系统性偏差：搜「梅西」这类**纯词条查询**时，
cross-encoder 偏向内容丰富的笔记，把真正的权威答案（实体词条页）挤下去。
词条精确命中必须**绕过重排**。

## 2. 验收标准（AC）

- [x] AC1：查询精确命中词条名/别名时，该词条被 pin 住，不参与重排竞争
- [x] AC2：pin 住的文档排在重排结果之前
- [x] AC3：多个精确命中时，按实体路原始分排序
- [x] AC4：专名实体型 30 题 Hit@1 回到 **100%**

## 3. 测试用例

| 用例 | 命令 / 位置 | 期望 |
|---|---|---|
| TC1 单词条查询 | 搜「梅西」 | 实体「梅西」排第 1 |
| TC2 指标回归 | `node tests/eval_backend.js` | 专名实体型 Hit@1 = 100% |

这条是「重排不能盲信」的直接证据 —— 规则兜底比模型更可靠。
