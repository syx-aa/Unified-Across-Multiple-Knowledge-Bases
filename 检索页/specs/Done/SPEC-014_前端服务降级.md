# SPEC-014 前端服务探活降级

> 状态：Done ｜ 优先级：P0 ｜ 归属：前端 ｜ 更新：2026-10-23

## 1. 需求（Spec）

同一份页面要同时支持三种场景：线上（服务端可用）、本地起服务、
以及 `file://` 双击打开（没有服务端）。不能因为服务端不可达就报错。

## 2. 验收标准（AC）

- [x] AC1：页面加载时探测同源 `/api/health`
- [x] AC2：探活**超时 2.5s** 即判定不可达
- [x] AC3：可达 → 检索走服务端；不可达 → 自动回退内置 BM25
- [x] AC4：切换在页头提示，全程无硬错误
- [x] AC5：`file://` 双击可用（除大模型通道外功能完整）

## 3. 测试用例

| 用例 | 命令 / 位置 | 期望 |
|---|---|---|
| TC1 有服务 | `python server.py` 后打开页面 | 页头提示「服务端检索」 |
| TC2 无服务 | 双击 `index.html` | 回退 BM25，页面可用 |
| TC3 页面可用 | `python serve.py`（静态服务） | 同 TC2 |

三种打开方式均可用且不报错。这是「一份代码适配三种运行环境」的关键。
