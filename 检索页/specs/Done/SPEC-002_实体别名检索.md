# SPEC-002 实体 / 别名检索

> 状态：Done ｜ 优先级：P0 ｜ 归属：检索层 ｜ 更新：2026-10-23

## 1. 需求（Spec）

人物、球队、概念类查询直接命中词条页：`梅西` → 实体页，`无冕之王` → 荷兰。
支持别名跳转（`cr7` → C罗、`netherlands` → 荷兰），别名表来自 Wiki 模板 `index.md`。

边界：只查词条名与别名，不做模糊语义匹配。

## 2. 验收标准（AC）

- [x] AC1：词条名精确匹配可命中对应实体/概念页
- [x] AC2：别名表（`| cr7 | [[entity/C罗]] |`）被解析并生效
- [x] AC3：别名**大小写不敏感**（`CR7`/`cr7` 等价）
- [x] AC4：别名指向的目标若已不存在（被清理）则自动丢弃
- [x] AC5：纯词条名查询时，该词条**保底排在前**

## 3. 测试用例

| 用例 | 命令 / 位置 | 期望 |
