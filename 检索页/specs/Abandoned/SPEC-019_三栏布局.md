# SPEC-019 三栏布局与筛选面板

> 状态：Abandoned ｜ 原优先级：P1 ｜ 归属：前端 ｜ 归档：2026-10-23

## 1. 原需求

设计方案 v2（第四节）：
- **左栏**：类型筛选（笔记 / 实体 / 概念）+ 分类筛选
- **中间**：AI 答案卡（流式）+ 结果卡片（命中高亮）
- **右侧**：词条详情 / 笔记原文，含关联跳转

## 2. 为什么放弃

产品目标收敛了 —— 最终定义为「页面只有三样东西：
**一个提问框、一个搜索方式切换、大模型给出的答案**」。

理由：
- 这是一个**问答页**不是浏览器/阅读器，用户带着问题来，不是来逛知识库
- 三栏 + 筛选会挤压答案卡的视觉重心
- 无构建步骤的单文件页面，做复杂布局收益递减

## 3. 替代方案

单栏结构：提问框 → 搜索方式切换 → 答案卡（含来源列表与相似度）→ 检索过程面板（可折叠）。
需要看原文时点来源跳转，而不是常驻右栏。

## 4. 教训

方案的「信息架构」部分最容易过度设计。
先定清楚「用户来这一页要完成什么」，布局自然收敛。
